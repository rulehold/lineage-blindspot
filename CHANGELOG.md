# Changelog

## v0.2.0 — 2026-09-28
- New `data/breakdown.json` and report section: S and M3 by inferred family and by GGUF vs non-GGUF for samples C, B1 and B2 (same snapshot). A cell is published only with at least 5 inferred models and neither none nor all of them blind spots; only smaller cells are merged into "other", and a table that cannot meet the rule is left out (C family table). No value is hidden.
- `data/summary.json` is now generated by code: the internal `split` breakdown is no longer included and a `withheld` list is added (empty). All other values are unchanged from v0.1.1.
- Future snapshots will be checked against every earlier release before publication (samples with 1–4 changed models are withheld).

## v0.1.1 — 2026-09-28
- Headline wording: the 18.0% Chinese-origin figure is an *inferred* lineage and a lower bound (README, dataset card).
- Issue forms for sample requests, questions and data corrections (labels `topic:sample`, `topic:question`, `topic:correction`); `CITATION.cff`.
- Release notes now contain only the tagged version's section; `huggingface_hub` pinned to an exact version.
- Data unchanged: `data/summary.json` is byte-identical to v0.1.0.

## v0.1.0 — 2026-09-28
- First public release: aggregate lineage blind-spot measurements (rule set v1) on the 2026-09-27 Hugging Face snapshot.
- Files: `blindspot-public.md` (English + Korean), `data/summary.json`, `data/summary.json.sha256`.
- Aggregates only; no model ids or per-model verdicts.
